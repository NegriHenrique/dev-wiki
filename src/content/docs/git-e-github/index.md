O controle de versão é a espinha dorsal da colaboração em software: sem ele, equipes inteiras teriam seus códigos sobrescritos e nenhum histórico de evolução do projeto seria confiável.

:::note[A Ferramenta Universal]
Qualquer que seja a sua área (Frontend, Backend, Mobile, Inteligência Artificial ou Segurança), o Git e plataformas como o GitHub são o ambiente padrão de trabalho diário em praticamente 100% das empresas e comunidades de tecnologia do mundo.
:::

## Por Que Dominar Git e GitHub?

Aprender Git e GitHub desde o início da sua jornada destrava oportunidades únicas:

* **Trabalho em equipe sem atrito:** Múltiplas pessoas podem programar simultaneamente no mesmo arquivo sem perder alterações.
* **Segurança para errar e experimentar:** Crie ramificações (*branches*) para testar novas ideias; se algo der errado, você reverte o código ao estado anterior com facilidade.
* **Portfólio público comprovável:** Seus commits e Pull Requests no GitHub funcionam como um currículo vivo e público de código real.
* **Acesso ao ecossistema Open Source:** Capacidade de colaborar em bibliotecas, documentações e softwares abertos utilizados globalmente.

## Percurso Recomendado

Nossa trilha de Git está desenhada de forma sequencial para quem está começando:

1. **Fundamentos do Versionamento:** Entenda os três estados do Git (Working Directory, Staging Area e Repositório) e os comandos essenciais lendo o artigo [Introdução ao Versionamento com Git](/dev-wiki/git-e-github/fundamentos-e-configuracao/introducao-ao-versionamento/).
2. **Colaboração e Pull Requests:** Aprenda a bifurcar (*fork*), clonar, criar branches e enviar contribuições reais com o guia passo a passo [Como Fazer Seu Primeiro Pull Request](/dev-wiki/git-e-github/ramificacoes-e-colaboracao/como-fazer-seu-primeiro-pull-request/).
3. **Resolução de Conflitos e Boas Práticas:** Boas mensagens de commit e como integrar alterações da branch principal sem dores de cabeça.

:::tip[Pratique Criando Seus Próprios Projetos]
Crie um repositório no seu perfil do GitHub hoje mesmo para registrar os seus estudos e anotações. Cada commit diário ajuda a fixar o hábito e a desmistificar os comandos do terminal.
:::
