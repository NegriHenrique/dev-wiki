Escrever código é só parte do trabalho: ele precisa ser testado, empacotado, publicado e monitorado. A cultura DevOps aproxima desenvolvimento e operações para entregar software com mais frequência e menos sustos.

:::note[Do Seu Computador para o Mundo]
A frase "na minha máquina funciona" é o problema que contêineres, pipelines de CI/CD e infraestrutura como código vieram resolver.
:::

## Percurso Recomendado

1. **O que é DevOps:** cultura, princípios e ciclo de vida do software.
2. **Linux para desenvolvedores:** processos, serviços e permissões em servidores.
3. **Contêineres com Docker:** empacotando aplicações e dependências.
4. **Integração e entrega contínua (CI/CD):** automatizando testes e deploys.
5. **Computação em nuvem:** modelos de serviço e provedores.
6. **Deploy de aplicações:** publicando seu primeiro projeto.
7. **Observabilidade:** logs, métricas e rastreamento.
8. **Infraestrutura como código:** ambientes reproduzíveis e versionados.

:::tip[Comece Pequeno]
Antes de estudar orquestração e nuvem, publique um projeto simples e configure um pipeline de testes no GitHub Actions. A prática dá contexto para os conceitos mais avançados.
:::
