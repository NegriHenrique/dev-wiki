O desenvolvimento Frontend é a área da engenharia de software dedicada a projetar, construir e aprimorar a interface visual e a experiência de uso com a qual as pessoas interagem diretamente nos navegadores web e dispositivos móveis.

:::note[A Anatomia de uma Página Web]
Toda aplicação web moderna se apoia em três tecnologias fundamentais:
* **HTML:** Define a semântica e a estrutura dos conteúdos (textos, títulos, botões e imagens).
* **CSS:** Cuida da apresentação visual, cores, tipografia, espaçamentos e responsividade.
* **JavaScript:** Dá vida e interatividade à página, respondendo a cliques, requisições de rede e animações.
:::

## Por Que Aprender Frontend?

O Frontend é a porta de entrada para quem gosta de ver o resultado visual imediato das linhas de código escritas. Estudar esta área permite:

* **Criar produtos acessíveis e inclusivos:** Desenvolver interfaces que pessoas com diferentes necessidades e dispositivos consigam utilizar sem barreiras.
* **Compreender o motor do navegador:** Entender como a internet transmite arquivos e como o motor de renderização exibe cada elemento na tela.
* **Proporcionar experiências fluidas:** Otimizar o tempo de carregamento e a velocidade de resposta de aplicações interativas.

## Percurso Recomendado

Nossa trilha de Frontend está organizada na seguinte ordem pedagógica:

1. **HTML Semântico:** Estruturação correta de tags (`<main>`, `<article>`, `<header>`, `<form>`) para navegadores e leitores de tela.
2. **CSS Moderno:** Estilização, variáveis CSS, Flexbox, CSS Grid e design responsivo para diferentes tamanhos de tela.
3. **JavaScript no Navegador:** Tipos primitivos, escopo, funções e tratamento de eventos do usuário.
4. **Manipulação do DOM:** Como o navegador organiza a árvore de nós e como alterá-la via código. Leia o artigo [O Que É o DOM (Document Object Model)?](/dev-wiki/frontend/javascript-e-navegador/o-que-e-o-dom/).
5. **Consumo de APIs e Redes:** Realização de requisições assíncronas com `fetch` e manipulação de respostas JSON.

:::tip[Foco nos Fundamentos]
Antes de escolher frameworks populares (como React, Vue ou Angular), certifique-se de dominar HTML semântico, CSS puro e JavaScript moderno (*vanilla*). Os frameworks mudam com o tempo, mas a web permanece fundamentada nesses padrões abertos.
:::
