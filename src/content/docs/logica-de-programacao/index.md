Lógica de programação é o conjunto de regras e raciocínios estruturados utilizados para descrever a solução de um problema em passos bem definidos que um computador consiga executar. Dominar a lógica é o alicerce fundamental de qualquer carreira em tecnologia, independente da linguagem ou da área de atuação escolhida.

:::note[A Linguagem é Apenas uma Ferramenta]
Aprender a lógica equivale a aprender a pensar e desenhar a planta de uma casa; a linguagem de programação (JavaScript, Python, C) é apenas o idioma escolhido para comunicar essa planta ao computador.
:::

## Por Que a Lógica É Essencial?

Computadores não possuem intuição: eles executam comandos literais, na ordem exata em que foram instruídos. Desenvolver o raciocínio lógico permite que você:

* **Decomponha problemas complexos:** Quebre um desafio grande em instruções menores e gerenciáveis.
* **Identifique padrões:** Reconheça tarefas que se repetem e automatize fluxos manuais.
* **Escreva algoritmos determinísticos:** Garanta que para uma determinada entrada de dados, o programa sempre alcance a saída correta e previsível.
* **Transite entre linguagens com facilidade:** Quando a base algorítmica está consolidada, aprender uma nova sintaxe torna-se uma tarefa rápida.

## Percurso Recomendado

Nossa trilha de lógica é estruturada em uma sequência progressiva:

1. **Conceitos de Algoritmo:** O que são instruções sequenciais e entradas/saídas de dados.
2. **Variáveis e Tipos de Dados:** Como guardar números, textos (*strings*) e valores booleanos na memória.
3. **Estruturas Condicionais:** Tomadas de decisão no código com `if`, `else` e `switch`.
4. **Estruturas de Repetição:** Automação de loops com `for`, `while` e comandos de parada (*break* e *continue*). Leia o artigo [Estruturas de Repetição](/dev-wiki/logica-de-programacao/controle-de-fluxo/estruturas-de-repeticao/).
5. **Funções e Modularização:** Como encapsular blocos de código reaproveitáveis e com responsabilidades específicas.

:::tip[Como Estudar Lógica]
Não copie e cole blocos de código sem entender o fluxo passo a passo. Faça testes de mesa (acompanhe manualmente no papel o valor de cada variável a cada linha executada) para enxergar como o computador processa as instruções.
:::
