# Dev Wiki 📚

> Acervo colaborativo e aberto de conhecimento técnico para desenvolvedores, criado pela comunidade e para a comunidade.

O objetivo da **Dev Wiki** é reduzir a barreira de entrada para iniciantes no universo de desenvolvimento de software e no ecossistema open source. Fornecemos explicações técnicas de alta qualidade, diretas ao ponto, com linguagem acessível e foco absoluto em escaneabilidade.

> **Importante:** O intuito deste projeto é transmitir e consolidar conhecimento coletivo. Não somos especialistas absolutos nos tópicos abordados — somos pessoas colaborando e querendo se ajudar. Toda e qualquer correção, ajuste ou sugestão de melhoria é sempre muito bem-vinda!

---

## 🚀 Tecnologias

Este projeto foi construído utilizando as seguintes ferramentas:

* **[Astro](https://astro.build/)**: Framework web focado em conteúdo e performance.
* **[Starlight](https://starlight.astro.build/)**: Tema oficial de documentação do Astro com zero JavaScript por padrão e busca local via Pagefind.
* **Markdown & MDX**: Formato padrão para escrita dos artigos e tutoriais.

---

## 📂 Estrutura de Tópicos e Trilhas de Aprendizado

Nossos artigos estão organizados em um percurso sequencial progressivo:

1. **Fase 1: Primeiros Passos & Ferramental**
   * **Guia do Iniciante**: Orientações de estudos para novos profissionais e entusiastas de TI.
   * **Ambiente de Desenvolvimento**: Computador, sistema operacional, terminal, editores e internet.
   * **Git e GitHub**: Controle de versão, comandos essenciais e como enviar seu primeiro Pull Request no open source.
2. **Fase 2: Fundamentos da Programação**
   * **Lógica de Programação**: Raciocínio computacional, variáveis, condições, repetições e funções.
   * **Estrutura de Dados e Algoritmos**: De memória, listas e buscas a grafos, programação dinâmica e projetos práticos.
3. **Fase 3: Desenvolvimento de Aplicações**
   * **Frontend**: HTML, CSS, JavaScript, DOM, acessibilidade e performance.
   * **Backend**: HTTP, APIs, bancos de dados, autenticação e arquitetura.
   * **Infraestrutura e DevOps**: Linux, Docker, CI/CD, nuvem e observabilidade.
4. **Fase 4: Engenharia e Qualidade**
   * **Boas Práticas**: Clean Code, SOLID, refatoração, padrões de projeto e testes.
   * **Segurança**: OWASP Top 10, gestão de segredos, criptografia e LGPD.
5. **Fase 5: Carreira e Comunidade**
   * **Carreira**: Como estudar, portfólio, entrevistas, open source e soft skills.

> Artigos marcados como **Em breve** na barra lateral fazem parte do roadmap de escrita e ainda não têm conteúdo. Eles são ótimas oportunidades para a sua primeira contribuição!

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos

* [Node.js](https://nodejs.org/) versão 18 ou superior instalada.
* Gerenciador de pacotes `npm`, `pnpm` ou `yarn`.

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/seu-usuario-github/dev-wiki.git
```

2. Acesse a pasta do projeto:
```bash
cd dev-wiki
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

O site estará disponível no seu navegador em `http://localhost:4321`.

## 🤝 Como Contribuir

Toda contribuição é bem-vinda! Seja para corrigir uma vírgula, adicionar um exemplo prático ou escrever um guia completo, sua ajuda fortalece a comunidade.

1. Leia atentamente o nosso [Guia de Contribuição](CONTRIBUTING.md).
2. Verifique as tarefas com a tag `good first issue` no nosso rastreador de issues.
3. Não faça commits direto na branch `main`: sempre crie uma branch descritiva e envie um Pull Request.
4. Assine todos os commits com a flag `-s` (DCO - Developer Certificate of Origin).
